# sellauth-aio

An asynchronous Python wrapper for the Sellauth API. This library provides a fast, modern, and efficient way to interact with Sellauth services using Python's `asyncio`.

## Features

* Fully asynchronous API calls using Python's `async/await` syntax.
* Built for high performance and concurrency.
* Easy to integrate into modern asynchronous applications and Discord bots.
* Type-hinted for better IDE support.

## Requirements

* Python 3.8 or higher.
